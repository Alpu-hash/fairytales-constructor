# Этап 1. Утверждение темы дипломного проекта (черновик)

**Источник выбора темы:** аналогичная тема — расширение темы №18 «Генерация сказок» из списка тем университета (согласовать с куратором).

## Тема
Интерактивный генератор детских сказок на ночь на русском языке на основе языковой модели ruGPT3, дообученной методом LoRA, с интеграцией в Telegram-бота.

## Предпосылки
Сказка — один из первых жанров, с которыми сталкивается ребёнок, и традиционно считается средством, помогающим осваивать устройство социального мира: в безопасной форме она показывает, как взаимодействуют качества и поступки (смелость и страх, доброта и хитрость), и позволяет прожить переживания, недоступные в реальной жизни. Современные языковые модели умеют писать сказки, но обычно требуют от родителя умения формулировать запрос, не позволяют ребёнку пошагово влиять на сюжет и не гарантируют детский тон и безопасное содержание. Тема объединяет прикладную NLP-задачу (дообучение генеративной модели для русского языка) и практически значимый сценарий: интерактивную сказку, в которой ребёнок сам выбирает героя и действия.

## Описание задачи
Создать систему, которая по выбору ребёнка и родителя (герой, место, цель, настроение) пишет сказку на русском языке по главам, с главным героем-ребёнком и спокойной концовкой. Нужно дообучить предобученную модель на корпусе сказок, сравнить её с базовой моделью и с большой моделью через API, добавить фильтр безопасности для детей.

## Как вижу решение
1. Сбор и очистка корпуса, разбиение сказок на главы (до ~600 токенов, ограничение контекста ruGPT3).
2. Автоматическая разметка «карточки сказки» (герой, место, задача, мораль) для каждой главы и формат обучения: карточка + краткое содержание предыдущих глав + выбор ребёнка → следующая глава.
3. Дообучение ruGPT3 с помощью LoRA в Google Colab; серия экспериментов (ранг LoRA, число эпох, размер модели) с обоснованием параметров.
4. Оценка: перплексия на проверочной части, оценка людьми по шкале 1–5 (связность, сюжет, понятность ребёнку, мораль), доля сказок, где сохранено имя героя; проверка на сочетаниях выборов, которых нет в обучающих данных.
5. Фильтр безопасности для детского контента.
6. Сервер на FastAPI и Telegram-бот, запуск в Docker.

## База
Только открытые данные: тексты сказок на русском языке из русской Викитеки (общественное достояние): Андерсен, Гримм, Перро, Пушкин, Жуковский, Даль и другие авторы, а также народные сказки (около 1900 текстов-кандидатов). Источники и лицензии фиксируются в data/SOURCES.md. Данные и код со стажировки не используются.
